# Retirement Hacienda — shared site

Static site, no build step at serve time. Five pages, one job each:

| page | question it answers |
|---|---|
| `index.html` | the decision — shortlist, costs, the community plan |
| `report.html` | why here — regional evidence and the ranking |
| `dossier.html` | which parcel — twelve candidates, every photo reviewed |
| `scorecard.html` | what if we weight it differently |
| `map.html` | where |

Regenerate everything with `./build.sh` from the repo root. Published via GitHub Pages (Deploy from branch: main / root).
